# Secure Drop

## Netlify sozlamalari

Netlify saytining **Site configuration → Environment variables** bo‘limida `BOT_TOKEN` va `CHAT_ID` qiymatlarini kiriting. Ular Telegram orqali xabar va fayl yuborish uchun kerak.

Qora **PRESS** tugmasi parol oynasini ochadi. `0809` kiritilsa, `====salom=======` matni ko‘rinadi. Bu faqat brauzerdagi oddiy ko‘rsatish darvozasi; PIN source code ichida ko‘rinadi va haqiqiy himoya emas.
